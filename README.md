# IELTS Learning Workspace

This repository is organised around three study routes rather than file history.

## Start Here

| Area | Main entry | Use it for |
|---|---|---|
| Writing Task 1 | [Task 1 workspace](writing/task1/README.md) | Visual-type guides, language, practice and essay reviews |
| Writing Task 2 | [Task 2 workspace](writing/task2/README.md) | Views, templates, practice and essay reviews |
| Speaking | [Speaking workspace](speaking/README.md) | Plans, question banks, language and review notes |

## Study Loop

1. Choose the relevant guide or topic bank.
2. Complete one timed response.
3. Save detailed feedback in the corresponding review area.
4. Add only reusable patterns to the central notes.

Repository changes are summarised in [CHANGELOG.md](CHANGELOG.md).
