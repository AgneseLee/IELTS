# Part 2 Reflection Chains

复用逻辑，不复用整段。逻辑链决定展开顺序；6skills 解释具体行动为何有效。

- 先选 Chain，再根据叙事行动选 Skill。
- 每题引用叙事中至少两个具体细节。
- 保留 1 个 Primary Skill；Secondary Skill 必须有独立行动证据。
- 先说行动；能力名称最多出现一次。
- 复用 2–3 个熟悉短语，不照抄 `6skills.md` 整句。

| ID                   | 中文逻辑链                        |
| -------------------- | ---------------------------- |
| Problem-solving      | 问题 → 可控行动 → 结果 → 新习惯         |
| Perspective change   | 原有看法 → 具体证据 → 新判断标准 → 今后选择   |
| Role-model influence | 对方行动 → 品质/能力 → 对我的影响 → 关系/价值 |
| Experience growth    | 不适/意外 → 调整 → 收获 → 今后更愿意尝试    |
