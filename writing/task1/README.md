## 90-Second Route

| Task type | Guide | Main decision |
|---|---|---|
| Static data | [Static data](guides/data-static.md) | Ranking, gap, proportion or spending |
| Dynamic data | [Dynamic data](guides/data-dynamic.md) | Direction, peak, reversal or stability |
| Map | [Maps](guides/maps.md) | Past, present or proposed layout |
| Process | [Processes](guides/process-diagrams.md) | Linear or cyclical; start and endpoint |

### Visual-Type Index

| Visual | Main decision | Notes |
|---|---|---|
| Bar chart | Static or Dynamic | Choose by time pattern, not shape |
| Line graph | Usually Dynamic | Focus on direction, peak and reversal |
| Pie chart | Usually Static | Focus on share, rank and gap |
| Table | Static or Dynamic | Read the time dimension first |
| Mixed charts | Group by data relationship | Do not create one body paragraph per visual |

## Universal Four-Paragraph Structure

1. Introduction: accurately paraphrase the task.
2. Overview: report two main features; avoid detail overload.
3. Body 1: group related information.
4. Body 2: cover the contrasting group, remaining area or later stages.
