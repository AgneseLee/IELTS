## 1. 正向：说明好处

| Item | Notes |
|---|---|
| 用途 | 写优点、支持某个做法、说明某事值得鼓励 |
| 常见位置 | 主体段主题句或解释句 |
| 核心逻辑 | `A` 带来好处，并改善 `B` |

| 可记忆句型 | 中文含义 |
|---|---|
| `A brings substantial benefits.` | A 带来显著好处。 |
| `A can generate positive outcomes for B.` | A 能给 B 带来积极结果。 |
| `A plays an important role in improving B.` | A 在改善 B 方面起重要作用。 |
| `A helps to build a firm basis for B.` | A 有助于为 B 打下坚实基础。 |
| `A contributes to the long-term development of B.` | A 有助于 B 的长期发展。 |
| `One key strength of A is its ability to improve B.` | A 的一个重要优势是能改善 B。 |
| `A can make B more efficient and effective.` | A 能让 B 更高效、更有效。 |
| `A provides people with more opportunities to B.` | A 给人们提供更多机会去 B。 |
| `A not only brings immediate benefits but also creates long-term value.` | A 不仅有短期好处，也有长期价值。 |
| `This practice can lead to more sustainable and desirable outcomes.` | 这种做法能带来更可持续、更理想的结果。 |

**万能替换例子**

- Better education brings substantial benefits.
- Public transport can generate positive outcomes for urban residents.
- Allowing children to make mistakes contributes to their long-term development.

## 2. 负向：说明坏处

| Item | Notes |
|---|---|
| 用途 | 写弊端、反对某个做法、说明风险 |
| 常见位置 | 主体段主题句或结果句 |
| 核心逻辑 | `A` 带来问题，并损害 `B` |

| 可记忆句型 | 中文含义 |
|---|---|
| `A can produce harmful effects on B.` | A 会对 B 产生有害影响。 |
| `A may create serious problems for B.` | A 可能给 B 带来严重问题。 |
| `A places additional pressure on B.` | A 给 B 增加额外压力。 |
| `A can lead to a decline in B.` | A 可能导致 B 下降。 |
| `A may weaken B in the long run.` | A 长期来看可能削弱 B。 |
| `One major drawback of A is that it damages B.` | A 的一个主要缺点是它损害 B。 |
| `A often causes more problems than it solves.` | A 往往制造的问题比解决的问题更多。 |
| `A can increase the risk of B.` | A 会增加 B 的风险。 |
| `The negative impact of A should not be underestimated.` | A 的负面影响不应被低估。 |
| `A may bring short-term convenience, but it creates long-term costs.` | A 可能带来短期便利，但会造成长期代价。 |

**万能替换例子**

- Overusing private cars can produce harmful effects on the environment.
- Strict protection may weaken children's independence in the long run.
- Oil exploration can increase the risk of environmental damage.

## 3. 让步反驳：先承认再否定

| Item | Notes |
|---|---|
| 用途 | 写“虽然有道理，但我不完全同意” |
| 常见题型 | 讨论型、利弊型、观点型 |
| 核心逻辑 | 先承认 `A` 有一定好处，再指出它有限或有代价 |

| 可记忆句型 | 中文含义 |
|---|---|
| `Although A may bring some benefits, these benefits are limited.` | 虽然 A 有一些好处，但这些好处有限。 |
| `It is true that A can be useful, but this does not mean it is always desirable.` | A 确实有用，但不代表它总是值得提倡。 |
| `Admittedly, A has certain advantages, but its drawbacks are more serious.` | 不可否认 A 有优势，但缺点更严重。 |
| `While A may seem beneficial at first, its long-term effects are questionable.` | A 乍看有益，但长期效果值得怀疑。 |
| `This argument sounds reasonable, but it overlooks B.` | 这个观点听起来合理，但忽视了 B。 |
| `The advantage of A is often short-lived.` | A 的优势往往是短暂的。 |
| `However, this benefit may disappear once B happens.` | 然而，一旦 B 发生，这种好处可能消失。 |
| `Even if A brings some convenience, it should not come at the expense of B.` | 即使 A 带来便利，也不应以牺牲 B 为代价。 |
| `A may solve one problem, but it can create another.` | A 可能解决一个问题，但会制造另一个问题。 |
| `For this reason, the positive side of A should not be overstated.` | 因此，A 的积极面不应被夸大。 |

**万能替换例子**

- Although accepting a bad situation may reduce stress, this benefit is limited.
- While fossil fuel exploration may seem beneficial at first, its long-term effects are questionable.
- Even if strict rules bring order, they should not come at the expense of personal freedom.

## 4. 措施：提出解决办法

| Item | Notes |
|---|---|
| 用途 | 原因解决型、问题类作文、政府/学校/个人应该怎么做 |
| 常见位置 | 解决方案段主题句或解释句 |
| 核心逻辑 | 某个主体采取行动，以减少 `B` |

| 可记忆句型 | 中文含义 |
|---|---|
| `One practical measure is to ...` | 一个实际措施是…… |
| `Governments should take steps to ...` | 政府应采取措施去…… |
| `A more effective solution would be to ...` | 更有效的解决办法是…… |
| `It is necessary to encourage B to ...` | 有必要鼓励 B 去…… |
| `More resources should be invested in B.` | 应该把更多资源投入 B。 |
| `Schools / governments / companies should provide better support for B.` | 学校/政府/公司应为 B 提供更好支持。 |
| `Strict regulations should be introduced to reduce B.` | 应引入严格规定来减少 B。 |
| `Public awareness should be raised through education and media campaigns.` | 应通过教育和媒体宣传提高公众意识。 |
| `This problem can be addressed by improving B.` | 这个问题可以通过改善 B 来解决。 |
| `If this measure is implemented properly, it can reduce B significantly.` | 如果这一措施执行得当，可以显著减少 B。 |

**万能替换例子**

- One practical measure is to improve public transport.
- Governments should take steps to reduce the use of fossil fuels.
- Schools should provide better support for students who struggle academically.

## 5. 原因：分析为什么

| Item | Notes |
|---|---|
| 用途 | 解释现象、分析问题根源、展开观点 |
| 常见位置 | 原因段主题句或解释句 |
| 核心逻辑 | `A` 的发生由 `B` 导致，背后还有更深层问题 |

| 可记忆句型 | 中文含义 |
|---|---|
| `One major reason is that ...` | 一个主要原因是…… |
| `This is mainly because ...` | 这主要是因为…… |
| `A key factor behind this is ...` | 背后的一个关键因素是…… |
| `This problem is partly caused by B.` | 这个问题部分由 B 导致。 |
| `Another contributing factor is B.` | 另一个促成因素是 B。 |
| `The main reason for this trend is the increase in B.` | 这一趋势的主要原因是 B 的增加。 |
| `This can be explained by the fact that ...` | 这可以由……这一事实解释。 |
| `A happens largely because people tend to B.` | A 发生很大程度上是因为人们倾向于 B。 |
| `The root cause is not A itself, but B.` | 根本原因不是 A 本身，而是 B。 |
| `This situation reflects a deeper problem: B.` | 这种情况反映了一个更深层的问题：B。 |

**万能替换例子**

- One major reason is that many people rely too heavily on private cars.
- This problem is partly caused by poor urban planning.
- A key factor behind this is the lack of practical education.

## 6. 最实用组合模板

你可以把 5 类句子组合成主体段。

### 正向段

One key strength of `A` is its ability to improve `B`. This is mainly because `A` provides people with more opportunities to `C`. As a result, `A` not only brings immediate benefits but also creates long-term value.

### 负向段

One major drawback of `A` is that it can produce harmful effects on `B`. This problem is partly caused by `C`. If this continues, `A` may create long-term costs that should not be underestimated.

### 让步反驳段

Admittedly, `A` has certain advantages, but these benefits are limited. While `A` may seem useful at first, its long-term effects are questionable. For this reason, the positive side of `A` should not be overstated.

### 措施段

One practical measure is to improve `A`. Governments should take steps to provide better support for `B`. If this measure is implemented properly, it can reduce `C` significantly.

### 原因段

One major reason is that `A` has become increasingly common. Another contributing factor is `B`. This situation reflects a deeper problem: `C`.

## Exam Method

**考场使用口诀**

先选功能，再换变量。

**第一步：判断这一段要干什么**

- 讲好处：用 `正向`
- 讲坏处：用 `负向`
- 反驳对方：用 `让步反驳`
- 提办法：用 `措施`
- 分析原因：用 `原因`

**第二步：替换变量**

| Variable | Meaning |
|---|---|
| `A` | 题目中的行为/现象 |
| `B` | 影响对象 |
| `C` | 结果/原因/具体方式 |

这样你就能充分利用当前页面里的模板，又不会写得像硬套。
