## 如何使用

1. 先看原题，准备15秒，再自己说30–45秒。
2. 卡住时看逻辑链或点击E编号回到原练习；尽量先不看英文答案。
3. 对照答案检查直接性、机制和贴题例子；修改版保留你熟悉的核心表达。
4. 完成一次不看稿口述后再勾选。只将你自己重新组织的口述追加到练习记录，照读本文件不算新的原答案。

## 范围与编写标准

- 每题4–6句；一般Q5五句，其他问法四句，必要时补一条直接相关的限定。每题含一个用For example或For instance引出的贴题短例。
- 每题注明题型、一个主M机制、最多两个T主题、核心库原始逻辑链和可点击的E来源。M是论证角度标记；具体原因以列出的T链及已练内容为准，不为凑机制加入新观点。
- 原始逻辑链保留题库写法供回查；答案采用自然口语，不要求把链中的全部分支都说一遍。轻量限定只限制当前论点，不承担新的主论证。
- 例子是用于练习的常识性场景，不冒充你的个人经历。少数关于社会现象的判断采用I think、some或can等有限表达，不生成统计事实。
- A类124题在本目录全部已写；B类147题和C类41题尚未在本目录生成。既有全题答案库与实际练习记录的状态没有因此改为已口述。
