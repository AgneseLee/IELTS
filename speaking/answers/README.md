## 统一人设

- 湛江人，目前住北京；软件工程师，从业约八年。
- 好友 Stella：前同事，认识约三年；一起去过 Malaysia。
- 母亲：退休会计，耐心、务实、支持我。
- 高频事物：ChatGPT、童年作文、心理学书、笔记本电脑。
- 高频地点：湛江海边、北京公园、艺术馆、Malaysia/Semporna。

## 使用方法

1. P1 只记加粗部分和一个个人细节。
2. P2 先逐行看关键词复述，再用完整稿校正；关键词是检索线索，不是需要串读的句子。
3. P2 只复用信息结构，不逐字复用完整句；结尾从个人影响、感受、结果或记忆中选择一个方向即可。
4. P3 使用“立场—原因—例子—限制”结构。
5. 每次录音只修三个重复错误，然后立即重答。

## Part 2 时长与 Band 7 校准

- 每篇示范稿控制在 **210–230 词**。
- 以 **126–138 WPM** 的自然练习语速计算，目标时长约为 **1 分 40 秒**；停顿较多时可接近 2 分钟。
- Band 7 重点是连贯展开、准确的故事专属词汇和自然的复杂句，不靠生僻词或万能反思堆砌。
- 首次录音后用“实际词数 ÷ 实际分钟数”计算个人 WPM；如果连续两次超出 1:35–1:50，再按真实语速微调稿件。
