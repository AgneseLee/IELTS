# IELTS Writing Task 1：Process Diagram 模板

基于 sugar production 与 plastic-bottle recycling 两次练习。目标：首两段直接复用；正文只替换流程动作。

## 四段模板

### 1. Introduction

> The diagram illustrates the [number]-stage process used to [produce/recycle] [product/material].

### 2. Overview

> Overall, this is a [linear/cyclical] process that begins with [starting point] and ends with [end point]. [Optional defining feature: duration / phases / possible repetition.]

### 3. Body 1 — Preparation

> Initially, [input] is/are [step 1]. It/They is/are then [step 2], before being [step 3]. Following this, [next step].

### 4. Body 2 — Transformation

> During the remaining stages, [material] is/are [step]. Subsequently, [next transformation]. Finally, [final action], producing [end product].

## 首两段验证

### Sugar production

> The diagram illustrates the seven-stage process used to produce sugar from sugar cane.
>
> Overall, this is a linear process that begins with the cultivation of sugar cane and ends with the drying and cooling of sugar crystals. The agricultural phase takes between 12 and 18 months.

### Plastic-bottle recycling

> The diagram illustrates the nine-stage process used to recycle plastic bottles into new products.
>
> Overall, this is a linear process that begins with the disposal of used bottles and ends with the manufacture of consumer goods. Some products can potentially re-enter the same process.

## 使用规则

- `[number]-stage`：步骤明确才写。
- Overview：流程性质 + 起点 + 终点 + 一个显著特征。
- 正文连接器只需：`Initially / Following this / Subsequently / Finally`。
- 使用一般现在时；加工对象作主语时优先使用被动语态。
- `step` 表示具体动作；`stage` 表示较大阶段。
- 只写图中信息；不补充未展示的运输、地点、原因或结果。
