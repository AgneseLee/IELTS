## 2. 贯穿多数答案的共同逻辑

**担心工作、未来、AI → 失眠／焦虑 → 寻求改变 → 具体经历带来启发 → 调整想法或行动 → 压力缓解。**

反复被改变的旧观念是：

> I had to finish everything immediately and handle every challenge on my own to prove that I was strong and capable.

即：“我必须马上完成一切，而且独自解决，才能证明自己有能力。”

不同题目主要替换中间的触发事件：朋友谈话、书、比赛、旅行、园艺、工作调整等。**失眠是共用背景，真正需要区分记忆的是事件和启发。**

## 3. 七组已跨题复用的故事线

### S01 裁员后工作过量 → 求助、调整安排、建立边界

**覆盖：12 题。**

核心情节：公司裁员 → 我／Stella 工作量增加 → burnout、失眠 → 与经理沟通 → 调整优先级和不合理期限 → 晚上不回复非紧急消息／拆分任务／散步 → 逐渐恢复。

| 叙述视角 | 已覆盖题目 |
| --- | --- |
| 我主动改变 | 近期改变、近期改变的计划、重要决定、对结果开心的重要决定、长期目标 |
| 我观察 Stella 的改变 | 克服困难成功的人、做困难事情并成功的人、尊敬的年长者、有条理的人、改变重要想法 |
| 互相帮助 | 别人帮助我解决问题、我帮助别人改善健康 |

主要 reflections：

- **R3**：Strength includes asking for help and accepting support.
- **R5**：Never treat exhaustion as an achievement.
- **R4**：Break challenges into smaller, more manageable steps.
- **R2**：Focus on what I can control.
- **R6**：当旧方法不再适用时，调整计划与行动。

复用要点：同一类经历可以切换为“我做了什么”“她做了什么”“我们如何帮助彼此”。“有条理的人”要突出优先级、拆分任务和预留时间；“帮助健康”要突出倾听、散步和支持过程。

### S02 与 Stella 相处、谈心 → 感到被理解和支持

**覆盖：12 题。**

核心情节：我焦虑失眠 → 联系或见到 Stella → 一起做轻松的事 → 谈到工作和生活担忧 → 她倾听、开导并承诺支持 → 我放松下来。

| 场景分支 | 已覆盖题目 |
| --- | --- |
| 电话／消息 | 发小、长时间未收到回复 |
| 商场购物＋午餐 | 喜欢的建筑、高建筑、拥挤的地方 |
| 公寓聊天／聚会／吃东西 | 美好夜晚、印象深刻的聚会、特殊场合的食物、喜欢拍照的人、开心的人、喜欢历史的人 |
| 公园散步 | 城市中的自然之地 |

场景细节：

- 商场：买手链、上楼避开人群、午餐时谈心。
- 公寓：躺在沙发上、喝酒、聊文学／电影／音乐。
- 食物：Stella 做的特别饺子。
- 拍照：带相机、指导有趣的姿势。
- 公园：池塘、荷花、微风、虫鸣。

主要 reflections：

- **R8**：真诚倾听与支持，让人感到被理解。
- **R1／R3**：放慢节奏，允许自己接受帮助。
- **R9**：有意义的陪伴让普通地点和活动变得难忘。
- **R10**：历史题用更大的时间尺度重新看待担忧。
- **R12**：开心的人从日常小事中获得快乐。
- **R11**：公园题同时保留自然环境的放松作用。

复用要点：这是一个谈心故事家族，不应把全部场景当作同一天发生的一件事。每道题仍需保留其专属细节和结尾。

### S03 想通过聚会放松 → 发现无法真正交流

**覆盖：3 题——无聊的地方、嘈杂的地方、继续听不感兴趣的话。**

核心情节：失眠、想放松 → 去 Stella 公寓参加八到十人的聚会 → 大家谈钱、车、房子、感情八卦 → 我没兴趣、声音又很吵 → 格格不入、在人群里孤独 → 后悔参加。

主要 reflection：**R13 选择有连接感的社交。**

> Everyone was speaking, but no one was really listening.
>
> Not every gathering is worth saying yes to.

复用要点：“嘈杂”突出声音重叠、难以听清；“无聊”突出话题不合；“继续听”补清出于礼貌以及没有其他熟人可聊的原因。

### S04 心理书／动画视频 → 重新理解自己的压力

**覆盖：3 题——令人兴奋的书、包含动物的书、有趣视频。**

核心情节：失眠 → 读心理书／看心理动画 → 在角色的经历中看到自己 → 意识到自己总想立刻解决一切 → 放慢节奏、正视情绪 → 压力减轻。

- **书籍分支**：*Counselling for Toads*；Toad 与 Heron 的谈话；开始写下自己的感受。
- **视频分支**：可爱的动画角色；“Slow is fast”；反复观看。

主要 reflections：**R1、R2、R3**。

- 先理解自己出了什么问题，再采取行动。
- 面对自己的情绪，而不是压下去。
- 放慢速度有助于看清重点。

复用要点：“Slow is fast”可作为自己的总结；书籍内容与视频台词的归属应分别表达。

### S05 羽毛球运动员 → 训练、逆转、采访带来启发

**覆盖：6 题。**

| 分支 | 核心情节 | 已覆盖题目 |
| --- | --- | --- |
| 现场逆转 | 第一局失利 → 第二局落后 → 保持冷静、调整战术 → 赢下比赛 | 现场比赛、表现出色的运动员、钦佩的运动员 |
| 采访回顾 | 失眠时看采访 → 听运动员讲如何改变战术 | 名人采访、受欢迎的人 |
| 广告训练 | 球鞋广告 → 失误后继续练习 → “Slow is fast” | 名人广告 |

主要 reflections：**R6、R7、R1**。

- 根据反馈改变方法。
- 坚持可以包含改变方向。
- 成功需要持续练习，也需要适应能力。
- 将赛场上的调整迁移到自己的工作和生活。

复用要点：这是一个运动员素材包，包含比赛、采访、广告三个事件分支。

### S06 睡前刷短视频 → 设置明确停止点

**覆盖：2 题——浪费时间的活动、节约时间的方法。**

核心情节：下班疲惫 → 想靠刷视频放松 → 算法不断推荐 → 一刷一两个小时 → 没有真正休息、还挤占学习和睡眠 → 设置 15 分钟计时器、把手机放远。

主要 reflections：**R14、R5**。

- 看似放松的活动，未必带来真正的休息。
- 简单、明确的规则有助于改变习惯。
- 把时间留给真正想做的事。

复用要点：“浪费时间”强调问题与为什么持续做；“节约时间”强调办法、执行难点和效果。

### S07 噪声与光污染加重失眠 → 提议加强管控

**覆盖：2 题——想颁布的新法律、想颁布的环保法律。**

核心情节：工作压力导致失眠 → 夜间施工噪声和强光进一步干扰 → 希望加强管控 → 改善环境、睡眠和白天的状态。

两题的当前正文相同。主要 reflection：**R17 环境治理与日常生活质量直接相关。**

### 5.3 情绪结果与完整 Reflection 的区别

以下句子主要表达结果或感受：

- Some of my stress was relieved.
- I felt understood and supported.
- My sleep improved a little.
- I felt more confident.

完整的 reflection 通常进一步说明：

**以前怎么想 → 这次让我意识到什么 → 以后会怎么做。**

例如，工作故事不只写“我放松了”，还写出“从独自硬撑到主动求助”的观念变化。复习时可以先记住观念变化，再选一两个情绪结果收尾。

## 6. 材料一致性与版本差异

以下为分析时发现的差异，尚未修改原答案。

### 6.1 部分正文和 Story Bank 没有同步

| 题目 | 最新正文 | 旧辅助记录 |
| --- | --- | --- |
| 最不喜欢的电影 | 不认同主角靠运气成功 | 节奏过快、令人疲惫的动作片 |
| 不喜欢的短途旅行 | 地铁拥挤，也不喜欢目的地对应的工作 | 提早出门、听播客改善通勤 |
| 儿时技能 | 十岁跟父亲学骑车 | 写成九岁 |
| 开心的人 | 谈心、欣赏日月星辰等普通事物 | 仍有裁员后重建工作边界的背景 |
| 两道法律题 | 噪声与光污染管控 | 历史记录保留劳动保护法，已标注为上一版 |

因此，不能直接统计旧 Bank 标签来判断目前有哪些故事。法律题明确保留的历史版本也不应算成当前答案中的另一条故事线。

### 6.2 Stella 承担了多个角色

当前设定包括：童年好友、三年前工作认识的朋友、前同事、年长十岁的朋友，以及不同职业方向的人。

复用时应保留清楚的版本，尤其是“认识二十多年”与“三年前才认识”，不能混入同一人物介绍。创业和准备从事心理咨询也应作为独立故事分支记忆，除非另行建立连贯时间线。

### 6.3 六种能力不等于六种 Reflection

`6skills.md` 是能力分类，包含 Communication、Problem-solving、Learning、Adaptability、Leadership & Collaboration、Creativity & Innovation。

最新答案的内容主要集中于前四类。团队合作有明确的独立故事；创造力虽然能从手账等素材展开，但当前正文更强调专注过程和放慢节奏。

不要为了套能力标签，加入正文没有表现出来的行动或感悟。

## 7. 复习用的最简记忆框架

### 三层记忆

1. **共同背景**：工作与未来焦虑、失眠、想改变。
2. **故事动作**：求助经理、Stella 谈心、比赛逆转、读书、旅行、设置计时器等。
3. **Reflection 核心**：慢下来、关注可控、接受支持、小步行动、建立边界、调整方法。

### 复习优先级

1. 先熟练 **S01–S07 七组跨题故事**，覆盖 40 题。
2. 掌握 **R1–R8 八类核心 reflections**，理解彼此的区别。
3. 为 **S08–S24** 各记住一个关键动作和一个题目专属感悟。
4. 每次练习都把结尾落回题目：为什么喜欢这个地方、为什么佩服这个人、为什么对决定满意等。

**最终目标：记住可组合的事件和思想，同时保留每道题自己的重点。**
